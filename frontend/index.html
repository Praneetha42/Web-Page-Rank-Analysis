About WebRank

WebRank is a Web Page Ranking and Link Analysis System developed using C and web technologies.

📌 Project Overview

WebRank is an Advanced Data Structures project that represents webpages as nodes and hyperlinks as edges in a directed graph. It calculates webpage importance using the PageRank algorithm.

🎯 Project Objectives

  • Represent webpages using graph data structures.
  • Analyze connections between webpages.
  • Calculate webpage importance using PageRank.
  • Provide webpage searching and ranking features.
  • Visualize webpage connections interactively.

💻 Programming Languages

C

Backend logic and PageRank calculation.

HTML

Website structure and content.

CSS

Website styling and layout.

JavaScript

Frontend interactions and API communication.

🧩 Data Structures Used

Graph

Represents webpages as vertices and hyperlinks as directed edges.

Adjacency Matrix

Stores webpage connections using a two-dimensional array. A value of 1 indicates a link, while 0 indicates no link.

links[MAX_PAGES][MAX_PAGES]

Arrays

Store webpage names, PageRank scores, and other webpage information.

⚙️ Algorithms Used

PageRank Algorithm

Calculates the importance of webpages based on incoming links and the importance of linking pages.

Linear Search

Searches for a webpage by comparing its name with stored webpage names.

🛠️ Core Technologies

  • C Backend: Handles webpage management and ranking.
  • Mongoose: Provides the embedded C web server.
  • HTML, CSS, JavaScript: Develop the interactive frontend.
  • File Handling: Stores webpage information in website_data.txt.
  • API Endpoints: Connect the frontend with the C backend.
