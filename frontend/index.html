About WebRank

Understanding the project and its technology.

Project Overview

WebRank is a Web Page Ranking and Link Analysis System that analyzes relationships between webpages and calculates their importance using the PageRank algorithm.

Core Technologies

Frontend: HTML, CSS and JavaScript

Backend: C Programming Language

Web Server: Mongoose

Data Structure: Adjacency Matrix

Searching: Linear Search

Ranking: PageRank Algorithm

Storage: File Handling

Project Objective

To represent webpage relationships as a directed graph and rank webpages according to their importance and incoming links.
